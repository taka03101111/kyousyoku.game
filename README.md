# 暗号鬼討伐 — CRYPTO ONI BATTLE

高校「情報Ⅰ」の暗号技術を題材にした、全10問の4択クイズゲームです。大学の模擬授業や個人での復習を想定しています。

## 遊び方

- 1問20秒。10問中8問以上の正解で暗号鬼「サイファ」の討伐に成功します。
- クリック・タップ、A〜Dキー、1〜4キーで回答します。
- 回答後に正解と解説を表示します。「次の問題へ」を押すまで時間は進みません。
- タブが非表示になると一時停止し、戻ると残り時間から再開します。
- 8正解で討伐ゲージが満タンになりますが、10問終了後に勝敗を判定します。
- 最終画面で全10問を振り返り、同じ問題に再挑戦できます。
- 音声ボタンでオリジナルの合成効果音を切り替えます。初期値はOFFです。
- 全画面ボタンは対応ブラウザで使用できます。スマートフォンでは選択肢が縦に並びます。

## 使用技術

HTML5、CSS3、Vanilla JavaScript。外部ライブラリ・フォント・API・データベース・バックエンドは使いません。音はWeb Audio APIでその場で生成します。ゲームは個人情報・成績を保存せず、ゲームから外部への送信も行いません。

キャラクター画像は依頼時に提供された参考画像を組み込んでいます。差し替える場合は `assets/cipher-oni.png` を置き換えてください。第2の参考画像は紫・シアン・ゴールドの演出と選択肢の方向性に反映しています。画像全体にCSSで浮遊・出題・被弾・回避・よろめき・討伐・勝ち誇る動きを付けています。手足を個別に動かすキャラクターリグは含みません。

## 起動方法（ビルド不要）

`index.html` をブラウザで開くだけで遊べます。ファイルはこのディレクトリ構成のまま保ってください。

Node.jsがある場合、ローカルHTTPサーバーも利用できます。依存パッケージのインストールは不要です。

```sh
npm start
```

表示されたローカルURL（既定値 `http://127.0.0.1:4173`）を開きます。終了はターミナルでCtrl+C。ポートを変える場合は環境変数 `PORT` を指定します。

## 問題データ

依頼時の要件書をもとに、最新の授業範囲に合わせて第1問と第6問を改訂しています。出題順と正答は `A, C, B, D, A, C, B, D, C, A`。第1〜4問が基礎、第5〜8問が標準、第9〜10問が難問です。

学習範囲は共通鍵暗号・公開鍵暗号・暗号の安全性の3分野です。

| 問 | 難易度 | 学習内容 |
| --- | --- | --- |
| 1 | 基礎 | 共通鍵の暗号化・復号で使う鍵の関係 |
| 2 | 基礎 | 共通鍵を安全に共有する必要性 |
| 3 | 基礎 | 受信者の公開鍵で暗号化 |
| 4 | 基礎 | 受信者の秘密鍵で復号 |
| 5 | 標準 | 公開鍵を公開できる理由 |
| 6 | 標準 | 共通鍵の漏えい後の対応 |
| 7 | 標準 | 計算量的安全性 |
| 8 | 標準 | 情報量的安全性・ワンタイムパッド |
| 9 | 難問 | 4人の全ペアで必要な共通鍵の数 |
| 10 | 難問 | 偽物の公開鍵による危険性 |

`id`、`topic`、`difficulty`、`question`、`options`、`correctIndex`、`explanation` を各問題に定義しています。

## テスト

Node.js 20以上で実行できます。

```sh
npm test
```

問題データの整合性、全問全選択肢の正誤判定、0〜10点の勝敗、二重回答、20秒の境界、遅延フレーム、回答後の停止、タブ非表示中の停止と再開、リトライ、相対アセット参照を確認します。実際のブラウザでの確認記録は `TESTING.md` にあります。

## GitHub Pagesへの公開

1. 新しいGitHubリポジトリに、このフォルダーの内容をアップロードします。`index.html` がリポジトリの直下に来るようにします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選びます。
4. **Branch** に `main`、フォルダーに `/(root)` を選び、**Save** を押します。
5. デプロイ完了後、Pages欄に表示されたURLを開きます。

`dist/` は不要です。すべてのアセットが相対パスなので、`https://ユーザー名.github.io/リポジトリ名/` の形式でも動作します。`.openai/`、`tests/`、`scripts/`、`package.json` はゲームの実行には不要です。

この納品ではGitHubリポジトリの新規作成・GitHub Pagesへの実デプロイは行っていません。Sites版は所有者向けのプレビューとして配信されるため、授業で全員に配る場合はGitHub Pagesで公開してください。

## 表示とアクセシビリティ

PCでは選択肢が2列、幅760px以下では1列です。小型画面・長い問題・解説では、可読性を保つため縦スクロールを使用します。正誤は文字・記号・色を併用します。OSの `prefers-reduced-motion` に応じて動きを止めます。問題・次へボタンにはキーボードフォーカスを移し、効果音なしでもプレイできます。
